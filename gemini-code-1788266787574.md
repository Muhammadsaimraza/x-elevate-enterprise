# Project Request: X-Elevate (AI-Driven X & LinkedIn Growth Platform)
# Role: Expert Full-Stack Developer

Please build a complete full-stack web application based on the following technical requirements and step-by-step flow. 

## 1. Tech Stack Requirements
* **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS. Utilize a premium typography stack (e.g., 'Plus Jakarta Sans' for headings and 'Inter' for body text) to ensure a high-end look.
* **Backend:** FastAPI, Python, Pydantic for data validation, WebSockets for real-time data streaming.
* **Database:** PostgreSQL (SQL database).
* **External Integrations:** X (Twitter) Developer API v2, LinkedIn API v2.

## 2. Step 1: Landing Page, Navigation & Footer
* Build a responsive Next.js landing page with a luxurious, high-contrast theme: Deep Black backgrounds, striking Golden accents (buttons, borders, icons), and crisp White text/elements.
* **Top Navbar:** Links for 'Home', 'About', 'Features', and 'World Specific Schemes'. Right-aligned 'Sign In' and 'Sign Up' buttons.
* **Hero Section:** Catchy headline explaining "16-Agent Swarm for AI-driven X and LinkedIn growth", subtext, and a primary Golden CTA button.
* **Features Section:** Grid of cards displaying core features including Cross-Platform Orchestration and Real-Time Analytics.
* **Comprehensive Footer:** Build a well-structured, aesthetic footer containing quick navigation links, legal pages (Privacy Policy, Terms of Service), social media icons, and a newsletter subscription input.

## 3. Step 2: Authentication & Database Flow
* **Sign Up (`/signup`):** Create a form with Name, Email, and Password. Send this to the FastAPI backend. Hash the password and save the user in the PostgreSQL `users` table. On success, auto-redirect to `/login`.
* **Login (`/login`):** Create a form with Email and Password. Validate against the PostgreSQL database via FastAPI. On successful authentication, generate a JWT token, set secure HTTP-only cookies, and redirect to `/dashboard`.

## 4. Step 3: Core Dashboard UI (`/dashboard`)
* Implement `/dashboard` as a protected Next.js route following the Black, Golden, and White theme.
* **Account Linking:** Include a settings section allowing the user to securely authenticate and connect both their X and LinkedIn accounts via OAuth.
* **Sidebar:** Fixed left navigation for Analytics, Agent Settings, and Billing.
* **16-Agent Swarm Interface:** The main content area must display a UI listing the exact 16 AI agents: 
  1. Trend Analyzer 
  2. Content Strategist 
  3. Thread/Carousel Generator 
  4. Reply Orchestrator 
  5. Analytics Reviewer 
  6. Hashtag & Keyword Optimizer 
  7. Competitor Monitor 
  8. Engagement Booster 
  9. Media Prompt Crafter 
  10. A/B Testing Manager 
  11. Scheduling Optimizer 
  12. Lead Generation Scraper 
  13. Brand Voice Guardian 
  14. Viral Hooks Engineer 
  15. Sentiment Analyst 
  16. Executive Summarizer 
  Show their active/idle status and current tasks routing to either X or LinkedIn.
* **Real-Time Metrics:** Add dynamic charts, graphs, and a live activity feed displaying real-time data (impressions, engagements, incoming posts) for both the connected X and LinkedIn accounts, fed by WebSocket connections.

## 5. Step 4: FastAPI Multi-Agent Backend
* Build a modular FastAPI architecture with separate routers for auth, users, agents, and WebSockets.
* **Agent Logic:** Create a Python structure to handle the orchestration of the 16 specific AI agents mentioned above, including logic to determine whether a strategy applies to X, LinkedIn, or both.
* **X & LinkedIn API Integration:** Write service functions in Python to handle OAuth flows for both platforms, fetch posts/tweets, analyze trends, and publish content based on agent decisions.
* **Real-Time Data Streaming:** Implement FastAPI WebSocket endpoints to stream live engagement metrics and account data from the X and LinkedIn APIs directly to the Next.js frontend.

## 6. Step 5: Dockerization
* Provide a `Dockerfile` for the Next.js frontend.
* Provide a `Dockerfile` for the FastAPI backend.
* Provide a `docker-compose.yml` file to orchestrate the frontend, backend, and PostgreSQL database containers together.
